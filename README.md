## 🌟 Features

- **3D Solar System Viewport**: Interactive WebGL solar system built with `three` rendering real texture maps for each project planet and a glowing center sun.
- **Heliocentric Orbital Motion**: Planets move smoothly in orbit around the center star while locking their bright texture face towards the sun.
- **Candidate & Project Inspection**: Select any planet (or click empty space to deselect) to inspect full project metrics, tech stack badges, live demos, and GitHub links.
- **Interactive REPL Terminal**: Embedded terminal shell supporting commands like `cat resume`, `ls projects`, `mlflow status`, and `overclock`.
- **Data Stack & Analytics Dashboard**: Real-time proficiency stats, active EDA query feeds, and interactive candidate profile cards.
- **Executive Resume Download**: Direct one-click download for `Akshat_Lakhera_Resume.docx`.

## 🛠️ Local Development

### Prerequisites
- **Node.js**: `v18+`
- **npm**: `v9+`

### Setup

```bash
# Clone repository
git clone https://github.com/GUNPARK-GOOKIM/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start local dev server
npm run dev
```

### Production Build

```bash
# Compile production bundle
npm run build

# Preview build locally
npm run preview
```
